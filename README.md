## 🚀 Featured projects

### [LiFi DCO-OFDM: ML DC Bias Optimisation](https://github.com/shreepragatheesh32-source/lifi-dcbias-ml-optimisation)
`Python` `NumPy` `scikit-learn` `PyTorch` `OptiSystem`

Master's research project. I built a physics-based simulation of a DCO-OFDM LiFi link
(LED nonlinearity, shot/thermal noise, ambient interference, multipath), generated a 9,000-sample
dataset, and compared six regression models for predicting the optimal DC bias voltage.

### [Expense Tracker CLI](https://github.com/shreepragatheesh32-source/expense-tracker-cli)
`C#` `.NET 8` `xUnit` `GitHub Actions`

Personal finance tracker with income/expense tracking, search, per-category summaries and JSON
persistence. Domain logic is kept separate from the console UI behind a storage interface, with unit
tests running in CI.

### [Railway Reservation System](https://github.com/shreepragatheesh32-source/railway-reservation-system)
`C#` `.NET 8` `xUnit` `GitHub Actions`

Ticket-booking engine with berth allocation, senior-citizen lower-berth priority, RAC and
waiting-list queues, and automatic promotion on cancellation.
